# β-Ga2O3 Vacancy Machine Learning

## Project Goal

This project aims to build a complete computational materials workflow for predicting oxygen vacancy formation energy in β-Ga2O3 using Density Functional Theory (DFT) and Machine Learning.

Rather than focusing on obtaining the best prediction accuracy, this project emphasizes understanding and implementing the complete research workflow from crystal structures to data analysis.
